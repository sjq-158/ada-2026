Linked List (Doubly)

The List ADT has the following operations that you are to implement on a Doubly Linked List:

void insert(int num): Inserts num into the last element of the list.
int get(int pos): Returns the integer in the _pos_th position. If the position is invalid, throw an exception that has a message "Invalid position".
int remove(int num): Removes the first occurrence of num from the list and returns the position to which it was found. If the number does not exist, return 0 instead.
void print(): Prints all the elements of the linked list, where on the first line shall print "FROM HEAD: " followed by the elements starting with the first element with a right arrow (->) separating the elements. On the next line shall print "FROM TAIL: " followed by the elements starting with the last element with a left arrow (<-) separating the elements. If there are no elements, output "(none)" instead for both the lines.
void size(): Returns the size of the list.
bool isEmpty(): Returns true when the list is empty; otherwise false.
void addAt(int num, int pos): Inserts num as the _pos_th position in the list. If the position is invalid, throw an exception that has a message "Invalid position".
int removeAt(int pos): Removes the element at the specified position pos. If the position is invalid, throw an exception that has a message "Invalid position".
 

Note that for those methods that have position as the argument, when the given position is closer to the tail then it is imperative that you traverse from the tail. This is to maximize efficiency when running the program. Also, when removing a node, the node must also be deallocated to prevent memory leak. These will be checked manually.

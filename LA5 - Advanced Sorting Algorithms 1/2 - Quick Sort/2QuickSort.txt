Quick Sort
Given the number of elements n and the said n elements, utilize Quick Sort to sort them.

For this Quick Sort, choose the first element as the pivot and identify the next few elements as smaller (a green) or larger (a purple) than the pivot. If it is green, it will be swapped with the first purple if it exists. If it is purple, do nothing. After the iteration, it will swap the pivot with the last green if it exists. Note that if the element is equal to the pivot, treat it as purple since it would be faster as it will do nothing.
Do this recursively. In this case, the sort_pivot method shall use the same global variable array and accept two integers: the start and the end which holds the first and the last index respectively to perform the sorting. Initially the start is 0 and the end is n-1 as it will sort the entire array. On the first iteration after the pivot is swapped, the left partition and the right partition shall be sorted next. Therefore a recursive call must be used for the left partition first, using the same start and the end is one before the pivot's index, then the recursive call to the right partition using the start being one after the pivot'_s index and the end being the same _end. Only do the recursive call when their start is less than their end. If it is equal, then there is only one element to be sorted and we know that one element here is already sorted.
In every swap of elements in the array, print the said array using the print() method.

# Design and Analysis of Algorithms
This contains all activities for Design and Analysis of Algorithms.

**Note:** Some problem filenames may contain "fixed," which indicates that the code has been re-checked within the program and is confirmed to be correct.

- 1 - Array List (Dynamic)
- 2 - Linked List (Doubly Linked List)

### LA2 - Arrays
- 1 - Largest Element

- 3 - Array Find
- 4 - Array Sum
- 5 - Binary Search
- 6 - Two Sum in Sorted Array

### LA3 - Sorting Algorithms
- 1 - Bubble Sort, Insertion Sort, Selection Sort (using pointer)

### LA4 - Recursive

- 2 - Recursive N
- 3 - Anything in Between

- 5 - Recursive Factors
- 6 - Collatz Conjecture
- 7 - Recursive Sum of Digits

- 10 - Fibonacci 

### LA5 - Advanced Sorting Algorithms 1
- 1 - Merge Sort (Singly Linked List)
- 2 - Quick Sort

### LA6 - Hash Table

### LA7 - AVL Tree
